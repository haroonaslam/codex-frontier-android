# Global Codex Guidance

These instructions apply across every project opened through Codex Frontier.
More specific project or directory `AGENTS.md` files may add to or override them.

- Work on the project, files, and outcome requested by the user.
- When requested, build, test, run, and stop processes belonging to that project.
- Use an applicable installed skill when the user invokes it or the request
  clearly matches its documented purpose.
- Do not modify, rebuild, update, restart, uninstall, clear, or reconfigure the
  Codex Frontier application or backend unless the user explicitly requests
  Frontier maintenance.
- Do not stop or modify unrelated applications or processes.
- Never expose authentication tokens, session credentials, signing material, or
  other secrets.
